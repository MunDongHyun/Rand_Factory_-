# 통합 테스트 체크리스트 — 2026-05-28

발표 시연 안정화용. 핵심 사용자 동선을 실제로 누르며 검증한다.
체크박스를 클릭하며 진행하고, 발견된 이슈는 맨 아래 "결과 정리"에 누적한다.

## 0. 사전 준비

- [✔] 테스트 계정 준비 (브라우저 시크릿 창 4개 동시 활용)
  - [✔] 관리자 (`a`) 계정 로그인
  - [✔] 매니저 (`m`) 계정 로그인 (또는 일반회원 → 승급으로 신규 생성)
  - [✔] 학습자 (`j`) 계정 로그인 (또는 초대 코드로 신규 가입)
  - [✔] 일반회원 (`c`) 계정 로그인 (또는 신규 가입)
- [✔] **R2 콘솔** 열어두기 — 객체 누적 확인용
- [✔] 시연용 데이터 미리 1세트:
  - [✔] 아티클 1개
  - [✔] 빈 커리큘럼 1개 (양식 미배포 상태)
  - [✔] 테스트용 학습자 1~2명 (실 데이터 더럽히지 않게)
- [✔] 알림함 정리 (이전 시연 알림 일괄 비우기)

## 1. 골든 패스 (발표 시연 시나리오)

### 1-A. 관리자 흐름

- [✔] 로그인 → 관리자 대시보드 진입
  - [✔] 통계 카드 (총 사용자 / 이번 달 가입 / 가장 많은 회사) 정상
  - [✔] 최근 활동 라인 차트 (7/14/30일) 정상
  - [✔] 카테고리 도넛 + 인기 아티클 TOP 5 정상
- [✔] 아티클 등록 패널 진입
  - [✔] 메타 입력 (DBR/HBR, 제목, 저자, 발행일, 카테고리, 원문 URL)
  - [✔] 본문 입력 (RAG 자동 인제스트 트리거)
  - [✔] **원본 PDF 첨부 (30MB 이하)**
  - [✔] 등록 성공 토스트
  - [✔] **R2 콘솔에 `articles/{id}/source.pdf` 객체 생성 확인**
- [✔] 주간 PDF 리포트 다운로드
  - [✔] 클라이언트로 PDF 다운로드됨
  - [✔] **R2 콘솔에 `reports/weekly/{user_id}/...pdf` 누적 확인**
  - [✔] 리포트 내 직전 주 대비 증감 지표 표시
- [✔] 월간 PDF 리포트 다운로드 (동일 검증)
- [✔] 회원 관리 패널
  - [✔] 검색 (이름/이메일) 정상
  - [✔] 역할 필터 (a/m/j/c/탈퇴) 정상
  - [✔] 역할 변경 / 삭제(소프트) / 복구

### 1-B. 매니저 흐름 — 신규 가입부터

- [✔] 일반회원 가입 → 매니저 승급 (`/api/users/me/upgrade`)
  - [✔] 회사 초대 코드 자동 발급 (`AC-...` 형식이 아니라 Crockford Base32 14자)
- [✔] 헤더 햄버거 → 매니저 메뉴 항목 노출
  - [✔] "커리큘럼 관리" / "학습자 관리" 메뉴 표시
- [✔] 학습자 관리 페이지 → 초대 코드 표시 + 복사 버튼
- [✔] 학습자 가입 유도 (시크릿 창에서 코드로 가입 → 회사 자동 상속)

### 1-C. 매니저 — 커리큘럼 생성 + 양식 배포

- [] 커리큘럼 관리 → AI 커리큘럼 생성 (제목/직무/기간/목표 입력)
- [ ] 주차별 계획 자동 생성 확인
- [ ] 저장 → 학습자 배정
- [ ] 1주차 첫 과제 → 양식 배포 모달 진입
  - [] **DatePicker로 마감일 선택** (`+1주` 칩 한 번 클릭)
  - [✔] D-Day 배지 표시 확인
  - [✔] Tiptap 에디터로 양식 작성
  - [ ] 배포 클릭
- [ ] 문서 내보내기 → TXT/PDF/DOCX 3가지 다운로드
  - [ ] **R2 콘솔에 `curriculum_exports/{cur_id}/...{txt,pdf,docx}` 누적 확인**

### 1-D. 학습자 — 과제 작성/제출

- [✔] 시크릿 창 학습자 로그인 → 배정 커리큘럼 조회
- [✔] 진행률 표시 (초기 0%)
- [✔] 1주차 과제 진입
  - [✔] 매니저가 배포한 양식 로드 (sanitize 거침)
  - [✔] D-Day 배지 / 마감일 표시
  - [✔] 본문 작성
  - [✔] 첨부 1개 추가 (PDF/PNG 등 화이트리스트 내)
  - [✔] 제출
- [✔] 제출 직후 → 매니저에게 알림 도착

### 1-E. 매니저 — 알림 + 피드백

- [✔] 매니저 헤더 종 아이콘 → 빨간 배지 (unread count)
- [✔] 알림 드롭다운 → 학습자 제출 알림 표시
- [✔] 알림 클릭 → 자동 딥링크 (학습자 관리 또는 커리큘럼 페이지)
- [✔] **자동 선택된 제출물에 2.4초 highlight 애니메이션 확인**
- [✔] 제출 카드 클릭 → 인라인 펼침 (본문 + 첨부 + 피드백 폼)
- [✔] 빠른 코멘트 칩 한 번 클릭 → textarea 채워짐
- [✔] 피드백 저장 → 학습자에게 알림 도착

### 1-F. 학습자 — 피드백 수신 + 진행률 갱신

- [✔] 학습자 헤더 종 → 피드백 알림 도착
- [✔] 알림 클릭 → 자동 highlight + 피드백 본문 표시
- [✔] 진행률 갱신 확인 (1주차 완료 비율 반영)

### 1-G. 매니저 — 수료증 발급

- [ ] 모든 주차 피드백 완료 (테스트는 1~2주차만 빠르게)
- [ ] 학습자 관리 → 수료증 발급 버튼 활성화
- [ ] 발급 → 수료증 PDF 다운로드
  - [ ] **R2 콘솔에 `certificates/{cur_id}/{learner_id}/...pdf` 누적 확인**
  - [ ] 수료증 번호 (`AC-YYYYMMDD-xxxxxx`) 정상

### 1-H. 학습자 — 수료증 다운로드

- [ ] 학습자 측에서 발급된 수료증 다운로드 확인

## 2. 엣지 케이스 (시연 외 운영 가드)

### 2-A. 마감일 검증

- [✔] 매니저 — 어제 날짜로 마감 설정 후 학습자 제출 시도
  - [✔] **400 차단** (`제출 마감일이 지났습니다`)
  - [✔] (정상 동작 확인 후 미래 날짜로 다시 설정)

### 2-B. 양식 1회 배포 잠금

- [ ] 학습자가 1주차 제출 완료된 상태에서
- [ ] 매니저가 1주차 양식 수정 시도
  - [ ] **400 차단** (`N주차 양식은 수정할 수 없습니다`)
- [ ] 동일 양식의 마감일만 변경 시도 → **통과** 확인 (양식 변경 X, deadline만)

### 2-C. 피드백 빈 텍스트 차단

- [✔] 매니저 — 피드백 textarea 빈 채로 "피드백 저장" 클릭
  - [✔] 토스트 경고 ("피드백 내용을 입력하세요")
- [✔] 매니저 — 빈 채로 "재제출 요청" 클릭
  - [✔] 토스트 경고 ("재제출 사유를 입력해야 합니다")
- [ ] 직접 API 호출 (Postman) → **백엔드 400** 확인

### 2-D. 첨부 파일 정책

- [✔] 학습자 — `.exe` 파일 첨부 시도 → 415 차단 (또는 프론트 화이트리스트)
- [✔] 학습자 — `.html` 파일 첨부 시도 → 차단
- [✔] 학습자 — 21MB 파일 첨부 시도 → 413 차단 (또는 프론트 가드)
- [✔] 학습자 — 빈 파일 첨부 시도 → 400
- [✔] 학습자 — 한글 파일명 PDF 첨부 → 정상 업로드 + 다운로드 시 파일명 보존

### 2-E. 권한 / 정보 숨김

- [✔] 일반회원 (`c`) — 햄버거 메뉴에 "커리큘럼 관리" / "학습자 관리" 메뉴 미노출
- [✔] 일반회원 — URL 직접 `/curriculum` 진입 시도 → 차단 또는 빈 화면
- [ ] 매니저 A — 다른 회사 매니저 B의 학습자 ID 직접 조회 → 404
- [ ] 학습자 — 다른 학습자의 제출물 조회 → 404
- [ ] 학습자 — 관리자 전용 아티클 원본 PDF (`/api/articles/{id}/pdf`) 직접 호출 → 404

### 2-F. 검색 분기

- [✔] 부적절 단어 검색 → 400 (`적절하지 못한 단어로 검색을 하셨습니다`)
- [✔] 무의미 입력 (`ㅋㅋ`, `aaa`) → 결과 없음 모달
- [✔] 정상 키워드 → 결과 정상

### 2-G. 알림 흐름

- [✔] 알림 드롭다운 → 알림 항목 hover 시 × 버튼 노출
- [✔] × 클릭 → 즉시 사라짐 + unread count -1 (안 읽은 거였으면)
- [✔] 헤더 "읽은 알림 비우기" 버튼 클릭
  - [✔] 읽은 알림만 일괄 사라짐
  - [✔] 안 읽은 알림 보호 확인
- [✔] "모두 읽음" 버튼 → 안 읽은 → 읽음 상태 변환

## 3. R2 콘솔 누적 확인 (5분)

각 prefix에 객체 1개 이상 새로 생겼는지:

- [ ] `task_attachments/{submission_id}/...` (학습자 제출 첨부)
- [ ] `articles/{article_id}/source.pdf` (관리자 아티클 원본)
- [ ] `curriculum_exports/{cur_id}/...txt`
- [ ] `curriculum_exports/{cur_id}/...pdf`
- [ ] `curriculum_exports/{cur_id}/...docx`
- [ ] `reports/weekly/{user_id}/...pdf`
- [ ] `reports/monthly/{user_id}/...pdf`
- [ ] `certificates/{cur_id}/{learner_id}/...pdf`
- [ ] `thumbnails/...` (기존, 새 등록 시 생성)
