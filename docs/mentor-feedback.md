# 멘토 피드백

멘토님 피드백, 팀 논의, 후속 액션을 날짜별로 정리하는 문서입니다.

## 사용 방법

- 피드백은 가능한 한 받은 날짜 기준으로 추가합니다.
- 원문을 보존하고 싶으면 `원문`에 넣고, 바로 실행할 내용은 `액션 아이템`에 정리합니다.
- 코드나 문서에 반영한 내용은 `반영 내역`에 커밋 해시나 파일명을 함께 남깁니다.
